# Coverage corpus — real Dutch the app has to be able to look up.
#
# You cannot write a list of the words that are MISSING from a dictionary:
# that's the nature of the problem. So completeness is measured the only way
# it can be — by running ordinary Dutch text through the real lookup pipeline
# (exact match → deinflection → decomposition) and requiring that a set
# percentage of the words resolve.
#
# `npm run validate` scores this file and fails the build if the rate drops
# below the floor in scripts/validate-dictionary.mjs. That check is what
# catches "some words are missing" — no rule about the data's shape ever
# could, because a missing word breaks no schema.
#
# The text is deliberately weighted towards what the walkthrough studies
# found people actually bring to the app: municipal and administrative
# letters (docs/studies/run-04-795d03e.md), then news, then everyday speech.
# Lines starting with # are comments; blank lines are ignored.
#
# When you add a section, add real sentences you have actually met — not
# sentences written to pass. The number is only worth having if the text is.
